# SwiftDesk releases

Downloads for **SwiftDesk**, a fast self-hosted remote desktop for Windows, macOS, Android and the web.

Website and guide: https://swiftdev.platformforge.dev

| Platform | File |
|---|---|
| Windows (host, the PC you control) | `SwiftDesk-Host-Setup-Windows.exe` |
| macOS 12+ (app + host, Intel and Apple silicon) | `SwiftDesk-macOS.pkg` |
| Android (app) | `SwiftDesk-Android-arm64.apk` |

Latest files are always at `https://github.com/luonghongthuan/swiftdesk-releases/releases/latest/download/<file>`.

The installers are not signed by Microsoft or Apple yet: Windows SmartScreen may say "unknown publisher" (More info, Run anyway) and macOS may ask you to open the package from Finder with right click, Open.
